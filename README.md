# ربات استخراج اطلاعات از نقشه گوگل (Google Maps Directory Scraper)

این یک ابزار ساده و قدرتمند برای استخراج اطلاعات کسب‌وکارها از نقشه گوگل است. با استفاده از این ابزار می‌توانید با وارد کردن نام شهر و حوزه فعالیت، لیستی از کسب‌وکارها را در قالب یک فایل اکسل مرتب و تمیز دریافت کنید.

## پیش‌نیازها

قبل از اجرای برنامه مطمئن شوید که موارد زیر روی سیستم شما نصب شده است:
1. **پایتون (Python)** نسخه 3.10 یا بالاتر

## نحوه نصب و راه‌اندازی

ابتدا پروژه را دانلود کرده و پوشه آن را باز کنید.
سپس در خط فرمان (Terminal / CMD / PowerShell) در مسیر پروژه دستور زیر را وارد کنید تا پیش‌نیازها نصب شوند:

```bash
pip install -r requirements.txt
playwright install chromium
```

## نحوه استفاده

این ابزار دارای یک رابط کاربری ساده و مدرن تحت وب است. برای اجرای آن، دستور زیر را در خط فرمان وارد کنید:

```bash
streamlit run app.py
```

پس از اجرای این دستور، یک صفحه وب در مرورگر شما باز می‌شود. در این صفحه:
1. **City (شهر):** نام شهر مورد نظر خود را وارد کنید (مثال: شیراز).
2. **Business Category (حوزه فعالیت):** نوع کسب‌وکار را وارد کنید (مثال: ناخن کار، رستوران، آرایشگاه، شرکت حسابداری).
3. روی دکمه **Start Scraping** کلیک کنید.

ربات به صورت خودکار یک مرورگر باز کرده و اطلاعات تمام کسب‌وکارهای مرتبط را جمع‌آوری می‌کند. 

## خروجی

پس از اتمام کار، فایل اکسل شامل اطلاعات زیر آماده دانلود خواهد بود:
- نام کسب‌وکار
- امتیاز
- تعداد نظرات
- دسته‌بندی
- آدرس
- شماره تماس
- آدرس وب‌سایت
- وضعیت باز/بسته بودن

می‌توانید فایل خروجی را مستقیماً از داخل همان صفحه وب با کلیک روی دکمه "Download Excel File"، دریافت کنید.
